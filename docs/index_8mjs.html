Detailed Description

JavaScript & WebAssembly bindings for the lob exterior ballistics solver.

Provides high-level Builder and Context classes for configuring and solving external ballistics trajectories with support for standard drag functions (G1..G8), piecewise BC velocity bands, custom Mach/Cd tables, wind profiles, Coriolis effects, and atmospheric corrections.
