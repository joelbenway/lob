lob Knowledge

lob computes the point-mass trajectory of a symmetric projectile: drag, gravity, wind, atmosphere, Coriolis, spin drift and aerodynamic jump. This bundle documents how it works, why it is shaped the way it is, and where the design decisions came from. The API reference alongside this bundle documents what to call.
