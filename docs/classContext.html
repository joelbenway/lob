Detailed Description

Compiled ballistic solver context produced by Builder.build.

Provides methods for forward solves (output drop and deflection in inches) and inverse solves (output elevation and windage in MOA).

◆ solveInverseFt()

Context::solveInverseFt ( rangesFt)
inline

Geometric inverse trajectory solution taking ranges in feet.

Computes elevation (drop compensation) and windage deflection as angular sight adjustments in Minutes of Angle (MOA). Positive elevation MOA indicates "dial up"; positive deflection MOA indicates "dial right".

Uses a closed-form geometric correction applied to the forward solution. Range 0 returns 0 MOA elevation and 0 MOA deflection.

Parameters
{NumberSequence}rangesFt Strictly ascending array or numeric TypedArray of ranges in feet.
Returns
{Array<{rangeFt: number, rangeYds: number, velocityFps: number, energyFtLbs: number, elevationMoa: number, deflectionMoa: number, timeOfFlightSec: number}>}
Exceptions
{TypeError}If rangesFt is not an array of numbers.
{RangeError}If ranges are negative, non-finite, or not strictly ascending.
